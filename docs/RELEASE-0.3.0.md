# Сменник 0.3.0 — технические изменения

## Добавлено
- Дополнительные места работы с индивидуальной ставкой.
- Отдельные графики, фактические часы, авансы и выплаты для каждого работодателя.
- Собственные повторяющиеся циклы из символов «Р» и «В», длина 2–60 дней.
- Календарное заполнение на 90 дней; сохранение ручных записей при обычной генерации.
- JSON v4 (места работы, принадлежность записей) с чтением v1/v2/v3.
- SQLite v4: старые записи остаются в `shifts` для основной работы, а дополнительные
  графики хранятся в `workplace_shifts`. Прошлые `work_sessions` и `wage_payments`
  получают `workplace_id=1` при миграции.

## Ограничения
- Одновременно возможна одна активная фактическая смена независимо от работодателя.
- Удаление работодателя не предусмотрено, чтобы случайно не потерять записи.
- Уведомления, доплаты за ночные часы и надбавки будут разработаны отдельно.
- Миграция проверяется через код и тесты сериализации, но требуется испытание
  реального обновления 0.2.0 → 0.3.0 на устройстве.

## Инварианты
- `applicationId=ru.smennik.app`.
- `versionName=0.3.0`, `versionCode=9` (предыдущая 0.2.0 — 8).
- Приватный ключ подписи НЕ включать в публичный репозиторий.
