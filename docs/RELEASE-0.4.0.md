# Сменник 0.4.0 — Умные финансы

## Реализовано
- Ночные часы 22:00–06:00 в локальном часовом поясе устройства, включая смены через полночь.
- Ночная надбавка в процентах от фактической ставки (0–200%) для каждого места работы.
- Надбавка за переработку сверх установленного порога (1–24 часа в рамках одной смены).
- Премии и удержания как отдельные виды финансовых операций; не считать их уже выплаченными.
- Расчёт начислений и остатка к получению с выделением компонентов.
- SQLite v5: три добавочных поля в workplaces. Переход с v1, v2, v3, v4.
- Резервная копия v5 с тарифными правилами, чтение файлов форматов v1–v4.
- Подпись APK старым сертификатом и версия Android 10, пакет ru.smennik.app.

## Известные ограничения
- Раздельные интервалы перерывов в старой базе не хранились: ночные минуты рассчитываются с
  пропорциональным вычетом общих перерывов по всей смене. Это оценка, не точный расчёт.
- Надбавки не выбираются в соответствии с законодательством автоматически: пользователь
  задаёт их на основании своего трудового договора. По умолчанию 0%.
- Переработка считается внутри каждой фактической смены, а не по нормативам недели/месяца.
- Нет учёта налогов, больничных, праздников, смен часового пояса и ручного исправления фактических минут.
- Уведомления и напоминания входят в следующий этап развития.
- Миграции SQLite и сохранение данных требуют проверки при обновлении 0.3.0 → 0.4.0 на реальном телефоне.
