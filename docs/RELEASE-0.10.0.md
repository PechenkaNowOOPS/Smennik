# Сменник 0.10.0 — независимые люди и их рабочие смены

## Реализовано
- Person(id,name), Workplace.personId; каждое место работы принадлежит одному человеку.
- Две верхние строки выбора: люди и их работодатели; календарь, финансы, статистика, история и операции ограничены текущим человеком.
- Создание человека с отдельной основной работой и переименование; максимум 50 профилей.
- SQLite v8 с persons и workplaces.person_id DEFAULT 1.
- При обновлении с существующих SQLite v1–v7 person #1 автоматически получает все старые работы, смены, оплаты и сессии без пересоздания их таблиц.
- Один текущий таймер на человека; одновременно могут работать таймеры разных людей.
- Активные Android-уведомления не перекрывают друг друга, кнопки адресованы конкретной сессии.
- Виджеты используют выбранного человека из локальной настройки приложения; плановые напоминания указывают имя.
- JSON резервная копия v9 включает persons и personId работодателей; старые v1–v8 остаются читаемыми.

## Изоляция данных
Все существующие таблицы смен и платежей привязаны к workplace_id. Данные человека выбираются через список его workplace.id, поэтому они не смешиваются в едином календаре и расчётах. Опция «Все работы» включает только работы выбранного человека.

## Проверки выпуска
- Gradle: unit tests и :app:assembleRelease через GitHub Actions.
- Android: applicationId ru.smennik.app, minSdk 26, versionCode 19.
- Перед установкой важно сделать копию. Фактическая установка поверх конкретного старого APK пока должна быть проверена на устройстве.
- Облачной синхронизации, сервера и регистрации нет; удаление профиля пока намеренно не предусмотрено.
