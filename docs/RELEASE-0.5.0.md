# Сменник 0.5.0 — Рабочий помощник

## Функции
1. Напоминания на Android через AlarmManager (не требуют права точных будильников).
2. Пользователь выбирает разрешение и интервал 15/30/60/120 минут; по умолчанию выключено.
3. После перезагрузки, смены часового пояса и обновления пакета пересоздание будильников.
4. Пересоздание будильников после изменения графика и импорта данных.
5. Карточки ближайших смен на главном экране.
6. Фактически завершённые смены можно исправлять (даты, время, общие паузы) и удалять с подтверждением.
7. Экспорт помесячного CSV отчёта по одному месту работы через Android Storage Access Framework.

## Совместимость
- Android versionName 0.5.0, versionCode 11, package ru.smennik.app.
- SQLite schema v5 **без миграции** от 0.4.0; резервная копия JSON v5 без изменения формата.
- Тот же приватный release signing certificate. Не публиковать keystore/password.
- Разрешения: POST_NOTIFICATIONS (Android 13+, динамический запрос), RECEIVE_BOOT_COMPLETED.
- Настройки уведомлений хранятся в SharedPreferences, **не попадают** в JSON-экспорт.
- Уведомления inexact: Android вправе задерживать доставку, особенно в энергосбережении.
- Требуется проверка установки 0.4.0→0.5.0 на телефоне и реального получения уведомления.
