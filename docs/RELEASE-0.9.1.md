# Сменник 0.9.1 — обратный отсчёт до конца смены

## Реализовано
- В карточке фактического рабочего времени на главном экране отображается **«ДО КОНЦА СМЕНЫ»** и HH:MM:SS.
- Отсчёт привязан к дате и времени **окончания запланированной смены**, а не к длительности оплаченного времени. Перерывы его не сдвигают.
- Для ночных и суточных смен учитывается переход на следующие календарные сутки; применяется часовой пояс устройства.
- После планового окончания показывается **«ВРЕМЯ СМЕНЫ ПО ГРАФИКУ ВЫШЛО»** и время сверх указанного конца.
- При отсутствии рабочего дня в календаре для той же даты и работодателя функция не показывает искусственное время окончания.
- Отсчёт вычисляется из времени устройства каждую секунду при открытом экране; отдельная фоновая служба не требуется.

## Совместимость
- `0.9.1` / Android `versionCode=18`, `applicationId=ru.smennik.app`.
- Схемы SQLite v7, JSON v8 и остальные механики учёта времени и зарплаты не изменены.
- В CI тестируется `:app:testDebugUnitTest` и собирается unsigned APK, предназначенный только для последующего подписания.
- Для установки поверх предыдущих release требуется **тот же самый приватный ключ подписи**; без настроенных GitHub Actions Secrets сборка готового устанавливаемого APK недоступна.
- Физическую установку и работу экрана на Android нужно проверить отдельно.
