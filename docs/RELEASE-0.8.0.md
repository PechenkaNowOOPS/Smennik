# Сменник 0.8.0 — технический отчёт

## Изменения
- Room не подключён: сохраняется существующий SQLiteOpenHelper.
- Добавлена таблица session_breaks (session_id, started_ms, ended_ms, paid).
- При v6→v7 таблицы смен, платежей и работодателей не удаляются.
- При v1→v7 выполняются прежние аддитивные миграции, затем создаётся таблица пауз.
- Для новых или подробно отредактированных завершённых смен все паузы проверяются:
  они находятся внутри смены и не пересекаются, длительность смены до 48 часов.
- Для старых записей поле total_paused_ms сохраняет исходный итог, а
  отдельные интервалы добавляют точность. Остаток сохраняется как минуты
  перерывов с неизвестным временем.
- Текущий таймер создаёт неоплачиваемые интервалы при возобновлении работы и
  при завершении на паузе. Изменения атомарные.
- Время оплачиваемых перерывов не вычитается из заработка.
- Ночная доплата: точный вычет известных неоплачиваемых интервалов;
  неизвестные минуты — пропорциональное распределение (оценка).
- JSON v8 и CSV содержат интервалы пауз, чтение старых JSON v1–v7.
- UI: создание пропущенной смены, исторический редактор и факт в календаре.

## Ограничения
- Для оплачиваемых перерывов во время запущенного таймера сначала заверши смену,
  затем отредактируй перерыв как оплачиваемый.
- Нет автоматического расчёта налогов и надбавок по законодательству: правила задаёт пользователь.
- На физическом телефоне требуется проверка установки поверх 0.7.1 и
  получения уведомлений после миграции.
- Android applicationId ru.smennik.app, versionName 0.8.0, versionCode 15.
