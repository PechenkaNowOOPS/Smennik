# Сменник 0.7.0 — персональные функции и выбор времени

## Реализовано
- Выбор часов/минут через системный 24-часовой TimePicker Android (планирование и массовые операции).
- Пресеты дневных, ночных и офисных смен; отсутствие ручного текстового ввода времени.
- Выбор даты и времени через два системных диалога при корректировке завершённой смены.
- Офлайн-виджет ближайшей смены среди нескольких работодателей; отдельный виджет зарплаты.
- Цели по заработку для каждого работодателя; проценты и остаток до цели.
- Повторение последней рабочей смены без перезаписи текущей даты.

## Совместимость и проверки
- Пакет ru.smennik.app, Android minSdk 26, versionName 0.7.0, versionCode 13.
- SQLite v6: добавочное поле в workplaces с DEFAULT 0 (не изменяет прежние записи).
- Восстановление резервных копий v1–v6, новый JSON формат v7.
- Работа полностью без сервера и аккаунта.
- Время окончания раньше начала трактуется как переход через полночь, одинаковое время — 24-часовая смена.
- Физическое тестирование установки поверх 0.6.0 и домашнего экрана требует проверки на устройстве пользователя.
