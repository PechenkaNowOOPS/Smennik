# Сменник 0.7.1 — обновление дизайна выбора времени

**Цель:** полностью убрать стандартные системные часы Android, сохранив понятный и точный выбор минут.

- Собственный Compose диалог с двумя сенсорными колёсами по 24/60 значений, инерцией и фиксацией.
- Единый ввод начала и конца смены; подсчёт длительности, перехода через полночь и оплаты.
- Четыре быстрых шаблона и до шести пользовательских избранных диапазонов.
- Применено в отдельной смене, генераторе графиков, массовом планировании.
- В истории фактического времени сохранён Android DatePicker только для даты; время выбирается через колесо.
- Сохранены: идентификатор ru.smennik.app, таблицы SQLite v6, резервное копирование JSON v7.
- Номер версии: 0.7.1 (versionCode 14).
- Шаблоны выбора времени хранятся локально в SharedPreferences, не включены в JSON-копию.

## Критерии проверки
1. Выбор 08:00–20:00, 20:00–08:00, 08:00–08:00 без ошибок длительности.
2. Прокрутка колёс, выбор минут 01 и 59, смена активного поля и подтверждение.
3. Сохранение и применение пользовательского шаблона.
4. Обновление приложения поверх 0.7.0 без удаления рабочих данных.
5. Совместимость финансовых и календарных расчётов.

*Установка на физическом устройстве и визуальная проверка анимации — отдельные испытания.*
