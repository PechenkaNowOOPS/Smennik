# Сменник 0.6.0 — Профессиональный календарь

## Критерии релиза

- Совместимый `applicationId=ru.smennik.app`, новый `versionCode=12` (предыдущий — 11), тот же подписывающий сертификат.
- SQLite `schema=5` без новой миграции (колонка type — строковый enum, значения расширены).
- JSON backup v6: экспорт новых типов дней и импорт старых v1–v5; форматы v6 не предназначены для старых APK.
- Все смены из 0.5.0 остаются в прежних таблицах и у прежних работодателей.
- Настроенные напоминания работают только для `DayType.WORK` и пересчитываются после операций массового изменения.
- Месячный, недельный и дневной календарь и общий вид работодателей.
- Даты выходных, отпусков, больничных и праздников не включаются в плановые рабочие часы.
- Обнаружение пересечений между работодателями, включая ночь и границу месяцев.
- Сдвиг выбранных смен на ±1–31 день с блокировкой занятого назначения (если не подтверждена замена).
- Массовые операции используют одну транзакцию, проверяют работодателя и не влияют на историю фактического времени и выплаты.
- Режим общей статистики без изменения сохранённых финансовых операций.

## Известные ограничения

- Отпуска и больничные не имеют расчёта оплаты: суммы требуют правил работодателя и законодательства.
- Конфликты основаны на плановых началах/окончаниях, без автоматического разрешения.
- График статистики показывает оценочные начисления на основании данных приложения.
- Ручной прогон на реальном Android-телефоне и визуальная проверка экранов выполняются отдельно.
