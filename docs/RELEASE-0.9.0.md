# Сменник 0.9.0 — Рабочий день 2.0

## Обновления
- Секундный таймер фактически отработанного времени, вычисляемый по сохранённым timestamp (не фоновому счётчику).
- Живое отображение оплаты, перерывов, процента выполнения плановых часов и переработок.
- Сравнение плановых и фактических начислений за месяц.
- Средний заработок за оплаченный час и оценочный прогноз к концу месяца.
- Два действия для активной смены в системном уведомлении Android: перерыв/продолжить и завершить.
- После действия из уведомления обновляются данные, виджеты и само уведомление.
- Android 13+: явный запрос разрешения уведомлений из активной смены; без разрешения таймер и основное приложение продолжают работать.
- При возврате в приложение выполняется перезагрузка состояния из SQLite, чтобы увидеть операции из уведомления.

## Совместимость и ограничения
- Нет аккаунтов, облака, передачи данных на сервер.
- Package ID ru.smennik.app и SQLite v7 / JSON v8 сохранены, формат пользовательских данных не изменён.
- Установка поверх старой версии возможна только при одинаковом signing certificate и версии versionCode меньше новой.
- APK требует подпись v1+v2 и проверку ZIP-выравнивания из-за ранее обнаруженных проблем установочного пакета.
- Уведомление **не является foreground service**; Android может скрыть его по своим правилам, но учёт рабочего времени останется в SQLite.
- Действия из уведомления применяются только к конкретной текущей активной смене.
- Реальная установка на устройство пользователя остаётся отдельным тестом; если установка отклоняется, нужен код ошибки PackageInstaller/adb.
