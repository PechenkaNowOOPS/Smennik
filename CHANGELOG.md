# История версий

## 0.1.3 — 2026-10-17
- Добавлена фирменная иконка приложения для Android Launcher: календарь смен на графитовом фоне с лаймовыми акцентами.
- Добавлены стандартная и круглая adaptive launcher icons (Android 8.0+) и monochrome icon для тематических значков Android 13+.
- Иконки подключены через AndroidManifest.xml (android:icon и android:roundIcon).
- VersionCode 4; логика графиков и база данных не менялись.

## 0.1.2 — 2026-10-17
- Исправлены 24-часовые и продолжающиеся ночью смены.
- 5/2 теперь понедельник–пятница.
- Изменена генерация циклов: полностью описывает каждый день (WORK/OFF) за 90 дней.
- Обычная перегенерация заменяет только автодни; ручные изменения сохраняются.
- Добавлен отдельный режим полной замены периода с явным подтверждением.
- Добавлена совместимая миграция SQLite v1→v2 и метка происхождения записи.
- JSON-копия v2 хранит происхождение дня и читает копии v1.
- Подсчёт часов показывает также оставшиеся минуты.
- Добавлены модульные тесты 24-часовых смен, ночных смен, 5/2, минут и резервного копирования.
- VersionCode 3. Запуск на устройстве ещё требует проверки.

## 0.1.1 — 2026-10-17
- Экран показывает загрузку графика и предлагает повторить чтение, если база данных недоступна.
- Редактор остаётся открытым до успешной записи или удаления; ошибки отображаются внутри диалога.
- Добавлены экспорт и восстановление JSON-копии через системный выбор файла Android.
- Импорт проверяет формат, SHA-256, размер, даты и дубликаты до изменения базы данных; замена данных выполняется одной SQLite-транзакцией после подтверждения.
- Автозаполнение графика принимает время смены и ставку.
- Повышен `versionCode` до 2.

## 0.1.0-alpha.1 — 2026-10-17

### Создано
- Новый Android-проект на Kotlin + Jetpack Compose.
- Тёмный интерфейс «Индустриальный табель»: главная и календарь.
- Локальное хранение смен в SQLite; для работы интернет не нужен.
- Создание и редактирование смен (включая ночные), отметка выходных, удаление записей.
- Генерация графиков 2/2, 3/3, 5/2, 1/3, 4/2 на 90 дней от выбранной точки старта без перезаписи существующих дней.
- Прогноз дохода по почасовой ставке; месячная статистика смен и часов.
- Unit-тесты расчётов и GitHub Actions для сборки debug APK.

### Ограничения
- Пока одна смена на дату, без синхронизации и фактического таймера.
- 5/2 — простой циклический шаблон от указанной даты (не автоматически понедельник–пятница).
- Финансовые суммы — прогноз начислений, не фактические выплаты.
- APK требует успешного запуска CI либо локальной Gradle-сборки; в среде подготовки Android SDK и Gradle отсутствуют.
