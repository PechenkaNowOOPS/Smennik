# История версий

## 0.3.0 — 2026-10-18

- Поддержка нескольких мест работы с отдельными графиками и ставками.
- Переключатель работодателя над четырьмя основными вкладками.
- Добавление новых мест работы с названием и почасовой ставкой.
- Раздельное отображение календаря, фактических смен, выплат и статистики.
- Произвольный повторяющийся цикл из рабочих (Р) и выходных (В) дней.
- Пользовательский цикл генерирует 90 дней; по умолчанию сохраняет ручные правки, полная замена требует подтверждения.
- Безопасная аддитивная миграция SQLite v3→v4 (v1→v4, v2→v4 также поддерживаются).
- Резервная копия JSON v4 сохраняет работодателей и принадлежность записей, читает v1–v3.
- Android versionCode 9; данные существующей «Основной работы» не меняются.

## 0.2.0 — 2026-10-17

- Новые разделы: «Финансы» и «Статистика», навигация по четырём вкладкам.
- Учёт фактического рабочего времени: начало смены, пауза, возобновление и завершение.
- Активная смена хранится в SQLite и восстанавливается после закрытия приложения.
- Добавлен учёт авансов и выплат заработной платы за выбранный месяц.
- Отдельные показатели плановых/фактических часов, смен, дохода и расчётного остатка.
- Календарь показывает отмеченные завершённые и выполняемые смены.
- Миграция SQLite 1/2 → 3 добавляет две таблицы без удаления существующего расписания.
- JSON-резервная копия v3 сохраняет графики, фактические смены и выплаты; старые v1/v2 поддерживаются.
- `versionCode=8`; `applicationId` и постоянный сертификат подписи не меняются.
- Неоплачиваемые перерывы вычитаются из фактического времени; расчёты приблизительные.

## 0.1.6 — 2026-10-17

- Добавлен отдельный диалог «О приложении» с фактическим номером версии, номером сборки и историей обновлений.
- Добавлена кнопка доступа к истории на главной странице.
- Подготовлен проверяемый выпуск, подписанный тем же постоянным сертификатом, что и 0.1.5.
- `versionName=0.1.6`, `versionCode=7`; идентификатор пакета и схема SQLite не изменены.
- Выполнить проверку обновления поверх 0.1.5 на устройстве после выпуска APK.

## 0.1.5 — 2026-10-17

- Добавлено единое версионирование из `version.properties` для Gradle.
- На главном экране отображается номер версии и номер сборки APK.
- Имя загружаемого артефакта GitHub Actions автоматически берётся из номера версии.
- CI проверяет формат SemVer и соответствие версии первой записи в CHANGELOG.
- Увеличен Android `versionCode` до 6; данные SQLite и логика смен не менялись.
- Постоянная подпись release APK по-прежнему требует GitHub Actions Secrets.

## 0.1.4 — 2026-10-17

- Подготовлена постоянная подпись release APK вместо нестабильной debug-подписи.
- Добавлена проверка отпечатка сертификата через apksigner в GitHub Actions.
- Публикация релизного APK требует секретов; без них workflow безопасно завершается ошибкой.
- Увеличен versionCode до 5; applicationId без изменений.
- Создан приватный комплект ключа и инструкции для владельца (вне GitHub).
- Внимание: одноразовая переустановка может потребоваться после прежней debug-сборки.

## 0.1.3 — 2026-10-17
- Добавлена фирменная иконка приложения для Android Launcher: календарь смен на графитовом фоне с лаймовыми акцентами.
- Добавлены стандартная и круглая adaptive launcher icons (Android 8.0+) и monochrome icon для тематических значков Android 13+.

## 0.1.2 — 2026-10-17
- Исправлены 24-часовые и продолжающиеся ночью смены.
- 5/2 теперь понедельник–пятница.
- Изменена генерация циклов: полностью описывает каждый день (WORK/OFF) за 90 дней.
- Обычная перегенерация заменяет только автодни; ручные изменения сохраняются.
- Добавлен отдельный режим полной замены периода с явным подтверждением.
- Добавлена совместимая миграция SQLite v1→v2 и метка происхождения записи.
- JSON-копия v2 хранит происхождение дня и читает копии v1.
- Подсчёт часов показывает также оставшиеся минуты.
- Добавлены модульные тесты 24-часовых смен, ночных смен, 5/2, минут и резервного копирования.
- VersionCode 3. Запуск на устройстве ещё требует проверки.

## 0.1.1 — 2026-10-17
- Экран показывает загрузку графика и предлагает повторить чтение, если база данных недоступна.
- Редактор остаётся открытым до успешной записи или удаления; ошибки отображаются внутри диалога.
- Добавлены экспорт и восстановление JSON-копии через системный выбор файла Android.
- Импорт проверяет формат, SHA-256, размер, даты и дубликаты до изменения базы данных; замена данных выполняется одной SQLite-транзакцией после подтверждения.
- Автозаполнение графика принимает время смены и ставку.
- Повышен `versionCode` до 2.

## 0.1.0-alpha.1 — 2026-10-17

### Создано
- Новый Android-проект на Kotlin + Jetpack Compose.
- Тёмный интерфейс «Индустриальный табель»: главная и календарь.
- Локальное хранение смен в SQLite; для работы интернет не нужен.
- Создание и редактирование смен (включая ночные), отметка выходных, удаление записей.
- Генерация графиков 2/2, 3/3, 5/2, 1/3, 4/2 на 90 дней от выбранной точки старта без перезаписи существующих дней.
- Прогноз дохода по почасовой ставке; месячная статистика смен и часов.
- Unit-тесты расчётов и GitHub Actions для сборки debug APK.

### Ограничения
- Пока одна смена на дату, без синхронизации и фактического таймера.
- 5/2 — простой циклический шаблон от указанной даты (не автоматически понедельник–пятница).
- Финансовые суммы — прогноз начислений, не фактические выплаты.
- APK требует успешного запуска CI либо локальной Gradle-сборки; в среде подготовки Android SDK и Gradle отсутствуют.
