# Сменник / Smennik

**Сменник** — офлайн-планировщик рабочих смен для Android: календарь, учёт времени, прогноз заработка и статистика. Приложение не требует аккаунта или постоянного подключения к интернету.

> **Статус: 0.1.2 — исправления расписания, debug APK собирается в GitHub Actions.** Реализованы локальное хранение, состояние загрузки, подтверждение записи и резервное копирование/восстановление через JSON. Проверка запуска на физическом устройстве ещё не выполнялась. Сервер и Telegram пока не реализованы.

## Цель

За несколько секунд показывать пользователю, **когда следующая смена, сколько времени осталось и сколько заработано** — без обязательной регистрации и постоянного интернета.

## Запланированные функции

- Календарь смен с шаблонами 2/2, 3/3, 5/2, 1/3, 4/2 и произвольными циклами.
- Корректное отображение смен, переходящих через полночь.
- Ручное изменение и массовое редактирование дней.
- Учёт плановых и фактически отработанных часов.
- Расчёт планируемого, начисленного и выплаченного дохода.
- Уведомления и настраиваемые напоминания.
- Локальная база данных и резервные копии.
- Telegram-бот `@Smenshik1_bot` и Mini App — в отдельном будущем этапе.

## Планируемый стек

| Часть | Технология | Статус |
|---|---|---|
| Android | Kotlin, Jetpack Compose | реализовано в модуле `app` |
| Архитектура | MVVM, разделение `ui` / `domain` / `data` | реализовано базово |
| Данные | SQLiteOpenHelper | локальное хранение и резервные копии |
| Фоновые задачи | WorkManager | планируется |
| Синхронизация | отдельный API и сервер, выбор технологии после уточнения требований | не решено |
| Telegram | Bot API + Telegram Mini App | планируется |

## План версий

- **1.0**: офлайн-календарь, шаблоны смен, учёт времени, базовый расчёт заработка, сохранение.
- **1.1**: таймер смены, уведомления, расширенная аналитика, экспорт.
- **1.2**: опциональная Telegram-синхронизация.
- **2.0**: несколько рабочих мест, совместное планирование, обмен сменами.

Это дорожная карта, а не список реализованных возможностей.

## Android-приложение

Исходники: [`app/`](app/); инструкция сборки: [`BUILDING.md`](BUILDING.md); изменения: [`CHANGELOG.md`](CHANGELOG.md). Данные остаются на устройстве в SQLite. Резервная копия экспортируется в JSON через системный выбор файла Android; импорт проверяет SHA-256 и заменяет график только после подтверждения. Room, фактические выплаты, уведомления и синхронизация остаются в дорожной карте.

## Изменения 0.1.2

- 24-часовая смена: одинаковые значения начала и окончания, например 08:00–08:00.
- Активная ночная смена отображается на следующий день до фактического завершения.
- Генератор заполняет и рабочие, и выходные дни на 90 дней вперёд.
- Повторная генерация заменяет только автоматически созданные дни; вручную заданные сохраняются.
- Полная замена всех дней периода доступна отдельно, с явным подтверждением; перед ней создайте резервную копию.
- График 5/2 всегда совпадает с понедельником–пятницей.
- Миграция SQLite 1 → 2 сохраняет старые записи с пометкой MANUAL.
- Формат резервной копии v2 сохраняет происхождение записей и умеет читать старые v1.

## Иконка приложения (0.1.3)

Launcher icon подключена в `AndroidManifest.xml` и реализована через адаптивные XML-ресурсы `mipmap-anydpi-v26` / `mipmap-anydpi-v33` и VectorDrawable. Поддерживаются цветная и монохромная тематическая иконки. Иконка не требует PNG-файлов и не влияет на базу данных или пользовательские сохранения.
